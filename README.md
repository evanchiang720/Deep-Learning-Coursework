# Deep Learning Course Projects (NYCU)

This repository contains my assignments and projects for the **Deep Learning** course, covering foundational neural networks, computer vision, generative models, and reinforcement learning.

---

## Overview of Labs

| Lab | Topic | Architecture / Methods | Key Frameworks |
| :--- | :--- | :--- | :--- |
| **Lab 1** | Backpropagation & Neural Networks | Multilayer Perceptron (MLP) from scratch | PyTorch, NumPy |
| **Lab 2** | Semantic Segmentation | U-Net, ResNet-34 U-Net (Oxford Pet Dataset) | PyTorch, Torchvision |
| **Lab 3** | Image Inpainting & Token Generation | VQ-GAN, MaskGIT, Transformer, FID evaluation | PyTorch, VQ-GAN |
| **Lab 4** | Sequence Learning / Video Prediction | Conditional VAE / Sequence-to-Sequence | PyTorch |
| **Lab 5** | Deep Reinforcement Learning (DQN) | DQN, Double DQN, Dueling DQN | PyTorch, Gymnasium |
| **Lab 6** | Generative Models | Conditional Diffusion Models (DDPM) | PyTorch |
| **Lab 7** | Policy Gradient RL | A2C & PPO (Inverted Pendulum, BipedalWalker) | PyTorch, Gymnasium |

---

## Tech Stack
* **Language**: Python 3.9+
* **Deep Learning**: PyTorch, Torchvision, TRL, Diffusers
* **Reinforcement Learning**: Gymnasium, Stable-Baselines concepts
* **Evaluation**: FID, mIoU, Episode Returns
